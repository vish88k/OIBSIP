# Temperature Converter

A responsive temperature converter built as part of the OIBSIP Web Development Level 1 Internship.

## About the Project

This project allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin. It includes input validation and absolute-zero validation for accurate and reliable conversions.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Convert between Celsius, Fahrenheit, and Kelvin
- Numeric input validation
- Absolute-zero validation
- Clear error messages
- Reset button
- Animated conversion results
- Responsive design for desktop and mobile
- Conversion formulas displayed for reference

## Conversion Formulas

- Fahrenheit = (Celsius × 9/5) + 32
- Celsius = (Fahrenheit − 32) × 5/9
- Kelvin = Celsius + 273.15

## Project Structure

- `index.html` – Structure of the converter
- `style.css` – Styling and responsive design
- `logic.js` – Temperature conversion, validation, reset and animation
