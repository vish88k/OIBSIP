# FocusFlow - Landing Page

## About

FocusFlow is a productivity-focused landing page designed to help users stay focused, organize their daily routine, and improve productivity.

## Objective

The objective of this project is to create a visually polished and responsive static landing page using HTML5 and CSS3.

## Technologies Used

- HTML5
- CSS3

## Features

- Sticky navigation bar
- Hero section with headline, subheadline, and call-to-action button
- Features section
- Focus experience section
- How It Works section
- Daily routine section
- Contact section
- Footer with links
- Consistent colour palette
- Responsive layout for different screen sizes
- Clean and readable typography
