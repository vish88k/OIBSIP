# FocusFlow - Landing Page

A modern and responsive productivity-focused landing page created for **FocusFlow**, a concept designed to help users stay focused, organize their daily routine, and improve productivity.

---

## 📖 About

**FocusFlow** is a productivity-focused landing page designed to present a clean and engaging experience for users interested in improving their focus and organizing their daily routine.

The website uses a modern layout with clearly separated sections, consistent typography, and a responsive design to provide a good experience across different screen sizes.

---

## 🎯 Objective

The objective of this project is to create a visually polished and responsive static landing page using **HTML5 and CSS3**.

This project focuses on practicing:

- Semantic HTML structure
- CSS styling and layouts
- Navigation design
- Typography and spacing
- Responsive web design
- Consistent visual branding

---

## ✨ Features

- 📌 Sticky navigation bar
- 🏠 Hero section with headline and subheadline
- 🔘 Call-to-action button
- ⭐ Features section
- 🎯 Focus experience section
- ⚙️ How It Works section
- 📅 Daily routine section
- 📩 Contact section
- 🔗 Footer with links
- 🎨 Consistent colour palette
- ✍️ Clean and readable typography
- 📱 Responsive layout for different screen sizes

---

## 🛠️ Technologies Used

- **HTML5** - For creating the structure and content of the webpage
- **CSS3** - For styling, layout, typography, and responsive design
