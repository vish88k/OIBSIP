# Personal Portfolio Website

A responsive personal portfolio website created as part of the OIBSIP Web Development Level 1 Internship.

This portfolio showcases my background, technical skills, projects, education, experience, achievements, and coding profiles.

- CSS3
- Bootstrap
- JavaScript
- Font Awesome

## Features

- Responsive design
- Animated hero section
- About Me section
- Technical Skills section
- Projects section
- Experience and Education
- Achievements
- Coding Profiles
- Contact section
- Smooth navigation

- `script.js` – JavaScript functionality
- `portfolioimage.jpg` – Profile image
- `screenshots/` – Project screenshots
