# Personal Portfolio - Landing Page

A modern and responsive personal portfolio website created to showcase my profile, technical skills, projects, and contact information in a clean and professional layout.

---

## 📖 About

This **Personal Portfolio** is designed to provide an online introduction to my professional profile and front-end development skills.

The website presents information about me, my technical skills, projects, and contact details through a simple, organized, and responsive interface.

---

## 🎯 Objective

The objective of this project is to create a clean and responsive personal portfolio website using **HTML5 and CSS3**.

The project focuses on practicing webpage structure, navigation, responsive layouts, typography, spacing, section organization, and consistent visual design.

---

## ✨ Features

- 🏠 Hero section with name and role
- 👤 Profile introduction
- 📖 About Me section
- 💻 Skills section
- 🛠️ Technical skills displayed in an organized layout
- 📂 Projects section with project cards
- 📝 Project titles and descriptions
- 🔗 GitHub project links/placeholders
- 📩 Contact section
- 🧭 Smooth navigation between sections
- 🎨 Consistent colour palette and branding
- ✍️ Clean and readable typography
- 📱 Responsive layout for different screen sizes

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design
