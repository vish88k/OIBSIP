# Personal Portfolio - Landing Page

A modern and responsive personal portfolio website created to showcase my profile, technical skills, projects, and contact information in a clean and professional layout.

---

## 📖 About

This **Personal Portfolio** is designed to provide an online introduction to my professional profile and front-end development skills.

The website presents information about me, my technical skills, projects, and contact details through a simple, organized, and responsive interface.

---

## 🎯 Objective

The objective of this project is to create a clean and responsive personal portfolio website using **HTML5 and CSS3**.

The project focuses on practicing webpage structure, navigation, responsive layouts, typography, spacing, section organization, and consistent visual design.

---

## ✨ Features

- 🏠 Hero section with name and role
- 👤 Profile introduction
- 📖 About Me section
- 💻 Skills section
- 🛠️ Technical skills displayed in an organized layout
- 📂 Projects section with project cards
- 📝 Project titles and descriptions
- 🔗 GitHub project links/placeholders
- 📩 Contact section
- 🧭 Smooth navigation between sections
- 🎨 Consistent colour palette and branding
- ✍️ Clean and readable typography
- 📱 Responsive layout for different screen sizes

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## 🖥️ Website Sections

### 🧭 Navigation Bar

The portfolio includes a navigation bar that allows visitors to easily move between the main sections of the website.

### 👋 Hero Section

The hero section introduces my profile with my name, professional role, and a short introduction.

### 👤 About Me

The About Me section provides a brief introduction about my background, interests, and focus in web development.

### 💻 Skills

The Skills section presents my technical skills in an organized layout, making it easy for visitors to understand my areas of knowledge.

### 📂 Projects

The Projects section showcases selected projects through individual project cards containing project titles, descriptions, and GitHub links or placeholders.

### 📩 Contact

The Contact section provides information for getting in touch and allows visitors to find the relevant contact details.

### 🔗 Footer

The footer provides additional information and links at the bottom of the portfolio.

---

## 📱 Responsive Design

The portfolio is designed to provide a good experience across different screen sizes:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

Responsive CSS techniques and media queries are used to adapt the layout and content to different screen widths.
